# UX Audit

AI-assisted UX auditing platform for turning website experiences into prioritized, actionable findings.

## Current vertical slice

- Next.js + TypeScript application
- Website URL input
- Audit API endpoint with URL validation
- Structured finding model with severity and recommendations
- UX score and findings dashboard
- Responsive visual foundation

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Roadmap

1. Capture and crawl the submitted website
2. Add accessibility and responsive checks
3. Add heuristic analysis with evidence/screenshots
4. Persist audits and projects in Supabase
